# 보물 여행 AR 탁본 (모든 코스)

주소: `/ar/course.html?id=코스아이디` (예: `/ar/course.html?id=seoul`)
메인 사이트의 모든 코스 상세 페이지와 카드에 'AR 탁본 시작하기'가 연결되어 있습니다.
`/ar/gyeongbok.html`은 경복궁 코스로 바로 넘어가는 주소입니다.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `course.html` | AR 화면 전체(표지, 지도, 장소, AR 카메라, 탁본첩, 보물 상자, 포인트 상품, A4 증명서). 모든 코스가 함께 씁니다 |
| `data/common.js` | 모든 코스 공통: 완주 상품(prizes), 1~5등 포인트 상품(pointShop) |
| `data/courses.js` | 메인 사이트 36개 코스를 변환한 자동 생성 파일 (직접 고치지 마세요) |
| `data/gyeongbok.js` | 손으로 다듬은 경복궁 특별 코스(문항·약도) |
| `js/treasure3d.js` | 3D 뷰어 (three.js, 안 되면 내장 렌더러) |
| `models/*.glb` | 임시 3D 보물 5종, 진화부(인장), 보물 상자 |

## 관리자 페이지와 연동 (서버)

AR 화면은 먼저 서버 `GET /api/ar/courses/:id`를 읽습니다. 관리자 페이지(전체 코스 등록)에서 경유지 좌표와
'AR 탁본 설정'을 고치면 1분 안에 반영됩니다. 완주 상품·포인트 상품은 관리자 'AR 상품 설정'에서 고칩니다.
서버가 응답하지 않을 때만 아래 정적 파일로 동작합니다. 자세한 내용은 `docs/AR-SERVER-GUIDE.md`.

## 코스를 고쳤을 때 (정적 예비 파일)

`bomul.html`의 코스(경유지·이야기·좌표)를 바꾸면 아래 명령으로 AR 데이터를 다시 만듭니다.

```
node tools/ar-courses/build.cjs
```

자동 변환 규칙: 비석에는 장소 이름, 수수께끼는 '탁본에 새겨진 이야기를 읽고 그곳의 보물 이름 고르기', 좌표는 `MAPGEO`, 참고 사진은 코스 대표 사진을 씁니다.
특정 코스를 경복궁처럼 직접 다듬고 싶으면 `data/gyeongbok.js`처럼 별도 파일을 만들어 같은 아이디로 등록하면 자동 변환본을 덮어씁니다.

## 저장되는 것

- 코스별 진행(탁본·보물·상자 개봉): 브라우저 저장소 `bomul-ar-코스아이디` (경복궁은 `bomul-gbg-v1`)
- 적립금·교환 내역·이름: 모든 코스 공통 지갑 `bomul-wallet-v1`. 코스마다 완주 적립금은 한 번만 지급됩니다.
- 실제 서비스에서는 회원 계정(서버)에 저장하도록 바꿔야 합니다.

## 테스트

- 휴대폰에서 https 주소로 열어야 카메라가 켜집니다.
- 주소 끝에 `&lite` 를 붙이면 내장 3D 렌더러로 봅니다.
