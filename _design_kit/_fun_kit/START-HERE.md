# 보물 여행 「재미 더하기」 키트

AR 탁본 화면(`client/public/ar/course.html`)에 네 가지를 더합니다. 서버를 바꾸지 않습니다. 기록은 각자의 휴대폰(브라우저)에 저장됩니다.

| 기능 | 어디서 | 하는 일 |
|---|---|---|
| **숨은 보물** | 지도 화면 위 「숨은 보물 탐지기」 | 코스 비석 가운데 한 곳 근처(45m)에 숨은 비석이 하나 더 있어요. 현장에서만 탐지기가 움직여요.<br>멀어지거나 가까워지면 얼음장 → 차가워요 → 미지근 → 따뜻 → 뜨거워요로 바뀌고 진동합니다.<br>도착하면 금빛 비석을 손가락으로 문질러 「○○ 인장의 숨은 조각」을 얻어요(+100P, 코스마다 한 번). |
| **보물 도감** | 아래 탭 「도감」 | 37개 코스, 166개 보물을 코스별로 보여 줍니다. 모은 보물은 내가 뜬 탁본으로 보여요. 등급은 보통·희귀·전설·숨은입니다.<br>8개 지역 세트(서울·경기인천·강원·충청·전라·경상·제주·옛이야기)를 모두 모으면 「○○ 수호자」 배지를 받고, 세트를 모두 현장에서 탁본했으면 +200P를 받아요. |
| **배지 18종** | 도감 탭 → 「배지」 | 첫 탁본, 새벽 탐험가(5~7시), 야행 탐험가(해 진 뒤), 비 오는 날 탐험가(날씨: Open-Meteo), 현장파, 완주 1·5·10코스, 숨은 보물 사냥꾼, 이야기꾼(엽서 공유), 지역 수호자 8종.<br>시간·날씨 배지는 현장 탁본일 때만 받아요. |
| **탁본 엽서** | 탁본 직후 결과 창, 탁본 크게 보기, 도감 | 내 탁본으로 1080×1350 엽서 이미지를 만들어 공유하거나 저장해요.<br>초대 링크(`?ref=코드`)를 함께 보냅니다. 링크로 들어온 친구에게는 「첫 보물은 무료로 체험할 수 있어요」라고 안내합니다. |

## 설치

```
node _fun_kit/install.mjs --dry
node _fun_kit/install.mjs
node _fun_kit/check.mjs
```

- **결제 키트와의 순서:** 결제 키트(_pay_kit) 전에 깔아도, 뒤에 깔아도 결과가 똑같습니다. 두 순서 모두 확인했습니다.
- **디자인·다국어 키트:** `bomul.html` 은 건드리지 않아 서로 충돌하지 않습니다.
- **되돌리기:** 원본은 `course.html.before-fun` 으로 백업됩니다.

## 꼭 알아 둘 것

- **숨은 비석 위치**
  - 기본 위치는 코스 비석 가운데 한 곳의 좌표입니다. 이미 있는 관람 장소라 안전합니다.
  - 다른 곳에 숨기려면 `client/public/ar/data/hidden.js` 에 좌표를 적으세요. 이때는 **직접 가서 확인한 안전한 곳만** 적어야 합니다. 관람 동선 밖, 출입 금지 구역, 차도, 물가는 안 됩니다.
- **현장 판정과 안전**
  - 탐지기는 코스 비석 1.5km 안에서만 움직입니다.
  - 걸으면서 화면을 보지 않도록 진동으로 알려 줍니다. 그래도 안내 문구를 함께 두는 걸 권합니다.
- **기록 저장 위치**
  - 포인트·배지·도감 기록은 지금 이 기기에만 저장돼 바꿔칠 수 있습니다.
  - 상품과 연결하는 포인트(숨은 비석 +100P, 세트 +200P)를 실제 교환에 쓰려면, 먼저 서버 지갑과 완주 인증을 붙이세요(CURSOR-PROMPTS-fun.md F-4).
- **초대 링크:** 지금은 누가 초대했는지 기기에 기록만 합니다. 초대 보상은 서버를 붙인 뒤에 정하세요.
- **언어:** 새 화면 문구는 한국어만 있습니다. 영어·중국어는 F-3 프롬프트로 추가합니다.
