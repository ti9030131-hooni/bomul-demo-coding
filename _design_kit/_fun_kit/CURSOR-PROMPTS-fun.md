```
_fun_kit/START-HERE.md 를 읽고, 새로 들어간 기능을 로컬에서 확인하는 방법을 단계별로 알려 줘.
코드: client/public/ar/course.html 의 「재미 더하기」 블록

확인할 것
1) 데모 모드로 탁본 1개
   - 「배지 획득 · 첫 탁본」 알림이 뜨는지
   - 결과 창에 「탁본 엽서로 공유하기」 버튼이 있는지
2) 엽서
   - 엽서 이미지가 만들어지는지
   - 이미지 저장·초대 링크 복사가 되는지
   - 휴대폰이면 공유 창이 뜨는지
3) 아래 탭 「도감」
   - 내 탁본이 보이는지, 지역 세트 칩, 배지 탭

5) ?ref=ABC123 을 붙여 열면 「친구 초대로 오셨네요」 알림이 뜨는지
문제가 있으면 원인과 최소 수정안을 알려 줘. 확인 없이 고치지는 마.
```

## F-2 · 숨은 비석 위치 직접 정하기 (선택)

```
client/public/ar/data/hidden.js 에 코스별 숨은 비석 위치를 적고 싶어.
1) 각 코스에서 지금 숨은 장소로 정해진 비석(hiddenSpot 규칙)을 표로 보여 줘.
   - 열: 코스 아이디, 비석 이름, 좌표, 구글 지도 링크
2) 내가 다른 좌표를 주면 hidden.js 에 { lat, lng, radius: 45, hint } 형식으로 넣어 줘.
   - hint 는 「○○ 근처 어딘가」처럼 장소를 바로 알려 주지 않는 문장으로
규칙: 좌표는 내가 직접 가서 확인한 것만 넣어. 네가 지어내거나 추정한 좌표는 절대 넣지 마.
```

## F-4 · 서버에 기록 남기기 (서버 완주 인증을 만든 뒤)

```
지금 숨은 비석·배지·도감 기록은 localStorage(bomul-hidden-v1, bomul-badges-v1)에만 있어.
서버 완주 인증(체크인·지갑)을 만든 뒤 아래를 서버로 옮겨 줘.
- 숨은 비석 발견
  · POST /api/ar/hidden { courseId, lat, lng, accuracy }
  · 서버가 hiddenSpot 과 같은 규칙(또는 hidden.js 좌표)으로 45m 안인지 확인한 뒤 +100P, 코스마다 1번
- 배지
  · GET/POST /api/ar/badges
  · 시간·날씨 배지는 서버 시각과 현장 체크인 기록으로 판단
- 세트 보너스 +200P 는 서버 체크인 기록(현장)으로만 지급
- 초대 링크
  · ?ref 코드를 회원가입 때 서버에 남겨
  · 보상은 내가 정할 때까지 주지 마
화면 쪽은 서버가 있으면 서버 값을, 없으면 지금처럼 localStorage 를 쓰게 해 줘. node:test 로 시험도 추가해 줘.
```

## T · 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 탐지기가 「?」에서 안 움직임 | 위치 권한, 코스 비석 1.5km 안인지. 데모(집)에서는 움직이지 않는 게 정상 |
| 「도감」 탭이 안 보임 | show() 의 탭 목록에 "v-dex" 가 들어갔는지(check.mjs) |
| 엽서 저장이 안 됨 | 앱 안 브라우저(카카오톡 등)는 다운로드를 막는 경우가 있어요. 「초대 링크 복사」나 길게 눌러 저장을 안내 |
| 비 오는 날 배지가 안 나옴 | 현장 탁본인지, api.open-meteo.com 에 접속되는지 |
| 엽서 글씨체가 다름 | 글꼴(Noto Serif KR)이 늦게 불러와진 경우. 다시 만들면 맞춰짐 |
