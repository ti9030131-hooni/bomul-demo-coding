# 새 메인 디자인 + 새 코스 지도 키트

미리보기로 확인하신 그대로를 지금 저장소에 넣는 키트입니다.

## 바뀌는 것
1. **메인 페이지(`client/public/bomul.html`)**: 검정·빨강 프로모션형 디자인
   - 맨 위 띠 → 히어로 "보물을 찾아라"(보물 상자·사선 띠·빛) → AR 탁본 체험 → 구역 바로가기 탭 → 총 완주 보상(1·2·3등 티켓)
     → 보물 여행 한눈에 보기(빨간 띠) → 사진 배너 → 추천 코스 → 이용 방법 → 다음 시즌(카운트다운 + 그리스 신화) → 유의사항
   - 예전처럼 별이 움직이는 배경
   - 코스 목록·상세·신청·문의·로그인 연결 등 **기능은 그대로**, 색만 같은 톤으로
2. **코스 지도 35장(`client/public/img/route-*.jpg`)**: 실제 좌표·해안선·행정경계로 다시 그린 지도(연한 회색 바탕, 남색·금색 표시)
   - 반나절 코스 2개는 자기 지도를 쓰도록 `bomul.html`의 지도 연결 2줄 변경
   - 경복궁 AR 코스는 손으로 그린 궁궐 배치도 그대로
3. **새 이미지 `client/public/img/hero-chest.webp`** (히어로 보물 상자)
4. **`tools/route-maps/`**: 코스 좌표를 고치면 지도를 다시 만드는 스크립트(선택)

## 순서 (10~20분)
1. 저장소를 Cursor로 엽니다(맨 위 폴더). 새 브랜치: `git checkout -b feat/main-design`
2. 압축을 풀어 나온 `_design_kit` 폴더를 저장소 맨 위에 둡니다.
3. Cursor 채팅을 **Agent 모드**로 열고 `CURSOR-PROMPTS.md` 를 1번부터 하나씩 붙여 넣습니다.
